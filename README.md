# 🎓 Thesis-2027  
## 📌 Project Name: Job Posting System  

## 📖 Project Overview  

**Thesis-2027 – Job Posting System** is a web-based platform designed to connect job seekers with companies.  
The system allows job seekers to apply for jobs, companies to post vacancies, and administrators to manage the entire platform.

The main goal of this project is to simplify the recruitment process and provide a centralized platform for managing job applications efficiently.

---

## 👥 Main Roles & Features  

### 1️⃣ Seeker (Job Seeker)

The **Seeker** is a user who searches and applies for jobs.

#### Features:
- Register & Login  
- Create and manage profile  
- Upload CV/Resume  
- Search and filter job vacancies  
- Apply for jobs  
- Dashboard to:
  - Track applied jobs  
  - View application status (Pending, Approved, Rejected, Interview, etc.)  
  - Manage saved jobs  

---

### 2️⃣ Vacancy (Company / HR)

The **Vacancy** role represents a company or HR who posts job opportunities.

#### Roles inside Vacancy:
- HR  
- Company Owner (Own Company / Own Vacancy)  

#### Features:
- Create company profile  
- Post new job vacancies  
- Edit/Delete job posts  
- View applicants  
- Download seeker CV  
- Update application status  
- Dashboard to manage:
  - Posted jobs  
  - Applications received  
  - Recruitment status  

---

### 3️⃣ Admin  

The **Admin** manages the whole system.

#### Admin Levels:
- Super Admin  
- Admin  

#### Features:
- Manage all seekers  
- Manage all companies  
- Manage all vacancies  
- Approve or reject company registration  
- Monitor system activities  
- Manage user roles & permissions  
- View reports and statistics  

---

## 🏗️ System Objectives  

- Provide a centralized job posting platform  
- Improve communication between job seekers and companies  
- Allow real-time tracking of application status  
- Ensure secure and organized data management  
- Provide administrative control over system activities  

---

## 🛠️ Technology Stack  

- **Frontend:** Flutter / React / Vue  
- **Backend:** Laravel / Node.js  
- **Database:** MySQL / PostgreSQL  
- **API:** RESTful API  
- **Authentication:** JWT / Laravel Sanctum
